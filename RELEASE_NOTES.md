# Hearts Of Assault Squad 0.2.0 — установка из одного окна

Скачай файл **Hearts-Of-Assault-Squad-v0.2.0-experimental-windows-x64.zip**
из Assets релиза. Архивы **Source code** GitHub предназначены прежде всего
для разработки; готовый архив содержит проверенный комплект установки.

1. Распакуй архив **целиком** в постоянную папку, например `D:\Games\Hearts-Of-Assault-Squad`.
2. Закрой HOI4, Men of War и редактор. Обе игры должны быть запущены хотя бы
   один раз ранее, чтобы появились пользовательские настройки и профиль MoW.
3. Дважды нажми **Install.cmd** и дождись сообщения **УСТАНОВКА ЗАВЕРШЕНА**.
   При стандартных путях ничего вводить не придётся. Если установок или профилей
   несколько, появится окно выбора. При отсутствии Python установщик предложит
   официальный Python 3.13 через Windows Package Manager.
4. Один раз включи моды: **HOI4 Men of War Bridge (experimental)** в лаунчере
   HOI4 и **HOI4_MoW_Bridge** в настройках MoW. После этого запускай
   **Start_Native_Bridge.cmd**. Папку установки не перемещай.

Установщик создаёт изолированный Python, ставит зависимости, скачивает
нужную версию hoi4_lua с проверкой SHA-256, подготавливает семь карт из твоей
MoW, регистрирует мод HOI4, подключает мод MoW и включает текстовые снимки.
Файлы игр, кампании и платные ресурсы в архив не входят. Сохранения кампаний
установщик не изменяет. Интернет нужен для Python, зависимостей и нативного компонента.

При обнаружении прежнего моста требуется подтверждение переключения.
Старые файлы и путь подключения сохраняются в `backups`; старые каталоги
игровых ресурсов рекурсивно не удаляются. При отказе в доступе Windows
покажет понятную причину: запусти Install.cmd от имени администратора.
Окно при ошибке не закрывается, журнал находится в `runtime/installer.log`.

Требования: **Windows x64, HOI4 1.19.3.0-c01a3d50, MoW AS2 3.262.1**.
Другие сборки HOI4 установщик отклоняет до изменения настроек игр.
Автоматизация меню рассчитана на русский интерфейс MoW и 16:10.
Релиз экспериментальный; подробные ограничения и обычный сценарий боя — в README.
