# Hearts Of Assault Squad

Экспериментальный мост **Hearts of Iron IV × Men of War: Assault Squad 2**.
Игрок выбирает конкретное стратегическое сражение в окне боя HOI4, проводит
его в MoW и возвращает проверенный результат в кампанию. Одновременно
разрешён один тактический бой; остальные сражения сами в MoW не отправляются.

## Реализовано

- Кнопка в окне боя, точное определение выбранного сражения и фоновый снимок
  HOI4 с постановкой на паузу. Нативный возврат потерь и отступления без
  загрузки изменённого сохранения, с проверкой результата и защитой от повтора.
- Состав по батальонам, фактическому оснащению и его поколениям; экипажи,
  масштабирование количества войск по организации с ненулевым минимумом.
- Страны MoW по стране HOI4 или идеологии, сложность по сложности кампании,
  запас боеприпасов по снабжению и оснащённости.
- Семь штатных карт MoW: выбор по местности, погоде и крупным городам.
  Геометрия новых карт не генерируется. Обычные бои работают в уже открытой MoW.
- Подготовка 60 секунд с временными границами движения/стрельбы; затем
  15 минут боя, точки, очки, видимый счёт и победа по очкам или уничтожению.
- Управление противником по ролям, обороняющиеся войска у точек,
  тыловая артиллерия и подвижные ПТ/зенитные орудия.
- Потери людей ограничены 25% за бой; поражение снижает организацию и
  предусматривает безопасное отступление. Есть отмена незавершённой миссии,
  резервные копии, отчёты ошибок и очистка подтверждённых служебных снимков.

Основной цикл проверен в игре. Это **не универсальный готовый мод для любых
версий**: нативные адреса привязаны к конкретной сборке HOI4. Полный набор
ограничений и история проверок находятся в [документации](docs/DEVELOPMENT_LOG.md).

## Требования

- Windows x64; Python **3.12+** с Tkinter; зависимости из `requirements.txt`.
- HOI4 **1.19.3.0-c01a3d50**, обычная кампания без Ironman и сторонних
  модов, меняющих игровые данные. Другие сборки нативный мост отклоняет.
- Men of War: Assault Squad 2 **3.262.1**, совместимые штатные ресурсы.
- Нативный runtime [hoi4_lua v0.5](https://github.com/ari-20/hoi4_lua/releases/tag/v0.5).
  Он скачивается отдельно; архив и два двоичных файла сверяются по SHA-256
  из `native_trial/manifest.json`. Бинарники и файлы игр в репозиторий не входят.
- Автоматизация меню MoW использует эталоны русского интерфейса и соотношения
  сторон 16:10. Для другой локализации/геометрии может потребоваться калибровка.
  Подготовленную миссию также можно открыть вручную — мост распознает её ID.

## Установка на новом компьютере

Команды ниже выполняются в папке проекта. Установленные игры не копируются
в GitHub. Для первой настройки обе игры должны быть закрыты.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Run_Python.cmd Configure.py --download-native --register-hoi
```

Настройщик находит стандартную Steam-папку и системную папку документов,
включая перенаправление в OneDrive. Если пути отличаются или профилей MoW
несколько, укажи их явно:

```powershell
.\Run_Python.cmd Configure.py --hoi4 "D:\SteamLibrary\steamapps\common\Hearts of Iron IV" --mow "D:\SteamLibrary\steamapps\common\Men of War Assault Squad 2" --hoi4-user "D:\Documents\Paradox Interactive\Hearts of Iron IV" --mow-progress "D:\Documents\My Games\men of war - assault squad 2\profiles\YOUR_PROFILE\game_progress.set" --download-native --register-hoi
```

Создаётся локальный `config.json`, который Git игнорирует. Имеющаяся
конфигурация автоматически не перезаписывается. `config.example.json` содержит
все параметры, включая политику потерь, таймеры и выбор карт.

1. В лаунчере HOI4 включи только **HOI4 Men of War Bridge (experimental)**.
   Пока игра закрыта, установи `save_as_binary=no` в её `settings.txt`, сохранив
   резервную копию. Фоновый снимок должен быть текстовым `HOI4txt`.
2. При закрытой MoW запусти `Prepare_Map_Bank.cmd`: он извлечёт семь карт
   **из твоей установленной игры** в локальную папку `runtime`.
3. Запусти `Connect_Mod.cmd`: он создаст ссылку из папки модов MoW в рабочую
   папку проекта. Прежний одноимённый мод сохраняется в `backups`. Для переноса
   старой папки игра и проект должны находиться на одном диске; права Windows
   могут потребовать отдельного запуска этого шага с повышенными правами.
4. В MoW включи **HOI4_MoW_Bridge**, один раз перезапусти игру и оставь её
   в главном меню. Для новых ресурсов или смены общей сложности иногда
   потребуется ещё один перезапуск; между обычными боями он не требуется.
5. Запусти `Start_Native_Bridge.cmd`, загрузи нужную кампанию в открывшейся
   HOI4. При первом использовании возьми отдельную тестовую копию кампании.

В `.venv` используется Python проекта. Для другого интерпретатора можно
задать переменную `BRIDGE_PYTHON`; путь к Codex не требуется.

## Обычный бой

1. Начни сражение в HOI4, открой его окно и нажми **«Симулировать в Men of War»**.
2. Не закрывай обработчик моста. Он поставит HOI4 на паузу, подготовит миссию
   и откроет её в MoW; индикатор показывает этапы подготовки.
3. Если предлагается ручной запуск, открой указанную в сообщении миссию в
   кампании **HOI4 — Men of War**. При необходимости нажми Пробел сам.
4. Доведи бой до итогового экрана. Победа по очкам полностью поддерживается;
   фактические потери считаются при любом способе победы.
5. Дождись **Strategic result applied and verified**. HOI4 остаётся на паузе.
   Перед следующим боем выйди из старой миссии в главное меню MoW.

Для отмены выйди из незавершённой миссии и запусти `Cancel_Unfinished_Battle.cmd`.
При ошибке загрузки уже подготовленной миссии используется `Retry_MoW_Load.cmd`;
кнопку HOI4 повторно нажимать не нужно. Если начался частичный возврат,
автоповтор блокируется: сначала изучается `live-return.json`. Сценарий
`Keep_Current_Campaign.cmd` сохраняет текущую кампанию и закрывает старую
попытку без дополнительных потерь; это осознанное восстановление, не обычный шаг.

## Статус и ограничения

- Пустынная Gazala пока не включена в проверенный банк: нет штатных точек.
  Для части местностей применяется явно указанное приближение.
- Очень большой состав может не поместиться на некоторых картах; вместо
  скрытого удаления войск генератор останавливается.
- ИИ управляется сценариями поверх штатного поведения игры. Полноценная
  замена сетевого режима «Линия фронта» и нативная загрузка MoW без меню
  остаются направлениями исследования.
- Старые `*_Trial.cmd` — инструменты разработки. Некоторые требуют локальных
  тестовых кампаний и файлов в `sessions`, которые намеренно не публикуются.
- Сохранения, `runtime`, резервные копии, локальные настройки и секреты
  исключены из Git. Отчёты нового боя создаются в `sessions/automatic`.

## Проверка исходников

```powershell
.\Run_Python.cmd -m unittest discover -s tests
.\Run_Python.cmd -m compileall -q bridge native_trial tests
```

На подготовленной версии пройдено 197 проверок основного моста; дополнительные
проверки установки находятся в `tests/test_distribution.py`. Тесты исходников
не заменяют игровой прогон на другом компьютере.
